Bookmarks Sync

Keep YouTube playlists and GitHub Lists separate, organized, and current.

YouTube Playlists

The extension creates a "播放清单" folder here, then places each playlist inside it.

Automatic update interval

Configured YouTube playlists and GitHub Lists are checked while Chrome is running.

YouTube playlists

A playlist folder is created only after the first successful sync.

GitHub Lists

GitHub Lists sync independently into a "项目清单" folder.

Not connected

Connect with the GitHub account already signed in to Chrome. The extension uses a one-time code and never asks for a password, personal access token, client ID, or client secret.

The extension creates a 项目清单 folder, then one folder for each GitHub List and repository bookmarks inside it.
